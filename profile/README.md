## Why it moved

This organization is named after a single product. The same author also
develops a Db2 incident-analysis client, and an organization named after one
product is the wrong home for a second one. The work is now published under a
neutral publisher organization, **Marek Pompura AI Labs**, which can carry
both.

This organization is kept so that its name stays reserved and this pointer
keeps working. It is not maintained otherwise.

## What the project is

A Java 21 Model Context Protocol server that gives AI assistants governed,
read-only access to IBM Db2 — typed MCP tools for schema exploration and
bounded diagnostic queries, with the policy decisions enforced by the server
rather than trusted to the model.
